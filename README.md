# Tower Defender

Самостоятельный проект Tower Defense на Babylon.js. Репозиторий полностью отделён от Starfall.

## Запуск локально

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Production-сборка и локальный просмотр:

```bash
npm run build
npm run preview
```

Babylon.js включается в локальную сборку Vite; CDN не используется.

## Игровой прототип

- Стартовый бюджет: 100.
- Gunner: 50 золота, дальность 6, урон 8, перезарядка 0,3 с.
- Мортира: 100 золота, дальность 9, урон 50, радиус взрыва 2,5, перезарядка 3 с.
- Магическая башня: 90 золота, дальность 4, урон 15, цепная молния до 3 целей.
- Обычный враг: 40 HP, скорость 2, награда 10, урон базе 1.
- Размер волны: 8 + 2 × номер волны; награда за зачистку 20 + 5 × номер волны.
- Улучшения до 3-го уровня, продажа за 50% вложенных средств.
- Управление касанием, пауза и скорость ×1/×2/×3.

Стоимость улучшений: 40 золота для уровня 2 и 60 золота для уровня 3. Каждый уровень увеличивает урон на 50%, дальность на 10%; перезарядка сокращается на 12%.

**Временный параметр прототипа:** здоровье базы — 20 единиц; значение не утверждено в игровом балансе.

## Управление

- Нажатие на свободную площадку открывает меню выбора башни.
- Нажатие на установленную башню открывает улучшение и продажу.
- Продажа возвращает половину всех вложенных в башню средств.
- Отдельного режима строительства и действия «Стереть» нет.
- Основной мобильный формат — горизонтальная ориентация.

## Технологии

- Babylon.js 7.54.3
- Vite 5.4.14
- ES modules
- GitHub Actions + GitHub Pages

## Публикация

После включения GitHub Pages с источником **GitHub Actions** сайт публикуется по адресу:

https://gipromeh.github.io/TowerDefender/

Каждый push в `main`, затрагивающий исходники проекта или workflow, запускает production-сборку и публикацию.

## Структура

- `src/scene.js` — 3D-сцена и камера.
- `src/game.js` — игровая логика.
- `src/main.js` — запуск сцены и обработка ошибок.
- `docs/SCENE_SCOPE.md` — исходная спецификация композиции сцены.
